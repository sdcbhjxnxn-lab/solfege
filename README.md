# 视唱练耳训练台

一个功能完整、可完全离线运行的**视唱练耳（Ear Training & Sight-Singing）**网页应用。
所有音频由 Web Audio API **实时合成**，五线谱由 **VexFlow 4** 渲染（本地固定版本），无需任何音频采样文件、无需联网、无需构建工具。

---

## 一、快速开始

### 方式 1：一键启动脚本（推荐）

**Windows**：双击 `start.bat`
**macOS / Linux / Git Bash**：`bash start.sh`

脚本会自动选择可用的运行时（Python 3 → Python Launcher → Node.js）启动本地服务，并自动打开浏览器访问 `http://localhost:8765/`。

可指定端口：`start.bat 9000`。若不希望自动打开浏览器，先执行 `set SOLFEGE_NO_BROWSER=1`。

> **关于 `start.bat` 为什么是纯英文**
> Windows `cmd.exe` 按**系统区域代码页**（简体中文系统为 936 / GBK）解析批处理文件。若把 `start.bat` 存成 UTF-8 并写入中文，中文会被当成 GBK 解码成乱码，进而破坏 `if (...)` 多行块与标签结构，报出一堆 `'xx' 不是内部或外部命令`。
> 因此该文件刻意**只用 ASCII 字符 + CRLF 换行**，在任何区域设置下都能正确执行。
> 如果你要自己往里加中文，**必须另存为 ANSI / GBK 编码**（VS Code：右下角编码 → Save with Encoding → GB2312/GBK），且保留 CRLF 换行。

### 方式 2：手动启动

```bash
# 任选其一，在项目根目录执行
python -m http.server 8765
python3 -m http.server 8765
node tools/serve.js 8765        # 零依赖，仅用 Node 内置模块
```

然后浏览器打开 `http://localhost:8765/`。

### 方式 3：直接双击 `index.html`

页面可正常浏览与练耳，但浏览器会**禁用麦克风**（`file://` 非安全上下文），因此 **视唱音准检测与逐音模唱不可用**。如需使用视唱功能，请使用方式 1 或 2。

> **为什么必须走 `http://localhost`？**
> `navigator.mediaDevices.getUserMedia()` 仅在安全上下文中可用。`http://localhost` 被浏览器视为安全上下文，而 `file://` 不是。

## 二、功能清单

### 1. 练耳（9 个题型，全部支持 初级 / 中级 / 高级 × 练习 / 测验 模式）

| 题型 | 内容要点 |
|---|---|
| 单音听辨 | 以标准音 a1（A4=440Hz）为参考音，判断目标音音名；初级限自然音级，中高级含升降音 |
| 音高比较 | 两音先后播放，判断高低或相同；高级含同音名不同八度的干扰项 |
| 音程听辨 | 初级限大小二/三度、纯四/五度、纯八度；中高级扩展至全部自然音程，含上行/下行与和声音程 |
| 和弦听辨 | 初级限原位大/小三和弦；中级加入增、减三和弦；高级加入四种七和弦，并按比例出「转位听辨」题 |
| 音阶调式听辨 | 初级限自然大/小调；中级加入和声、旋律小调与五声调式；高级加入中古调式、布鲁斯、全音音阶 |
| 和声进行听辨 | 先播主三和弦确立调性，再播和弦进行，判断罗马数字序列；高级加入小调与七和弦 |
| 音级听辨 | 给定调性，听辨单音的首调唱名与级数；高级加入变化音（升 fa / 升 sol） |
| 节奏听辨 | 先给预备拍再播节奏，从四个五线谱选项中选出正确的；覆盖 2/4、3/4、4/4 拍 |
| 旋律听辨 | 等时值音组（三音组 / 四音组 / 五音组），四选项均为五线谱，需读谱比对 |

**练习模式**：即时反馈 + 逐题解析 + 自动记录错题，可无限继续。
**测验模式**：固定 5 / 10 / 20 题，答题期间不揭示对错，结束后给出得分、评级、逐题回顾与一键重放。

### 2. 视唱（需麦克风）

- **谱例视唱**：按调性（C/G/F/D/Bb/A）、拍号（2/4、3/4、4/4）、小节数、难度自动生成调内旋律并以多小节五线谱呈现（含正确的小节线、调号、临时升降号与符杠）。
  - 播放主三和弦 / 调内音阶 / 全曲。
  - **可开关的循环节拍器**：点「节拍器」开始（按钮变为「暂停节拍器」并进入运行态），再点一次暂停；按钮右侧有每拍点亮的拍点指示，数量随拍号变化，首拍为重拍（音高更高）。
  - **速度（60 / 80 / 100 BPM）即时生效**。速度属于「播放属性」而非「作曲属性」，因此改速度**不会重新生成旋律**；节拍器运行中改速度会立刻按新速度重排下一拍。
  - 节拍器与参考播放互斥：按下「主三和弦 / 调内音阶 / 播放全曲」会先停掉节拍器；切换页内标签或在导航中离开视唱页也会自动停止，不残留定时器。
  - **逐音模唱**：逐音高亮目标音，实时显示音分偏差指针与偏差轨迹；偏差在 ±50 音分内保持 320ms 即判定该音准确，自动进入下一音；结束时给出准确音数统计。
- **音准仪**：自由实时音高检测，显示音名、固定唱名、音分偏差、频率与滚动偏差曲线。
- **节奏模仿**：播放节奏型，用户以空格键或点击击拍，按**击拍时间偏差（毫秒）**评分与可视化对照。

### 3. 乐理速查

音名与唱名对照（固定唱名 / 首调唱名）、音程速查表（半音数、协和度、听感、参考曲目）、和弦构成表（含试听）、音阶调式表、常用和声进行表（含试听）、**五度圈**（含调号）、**交互式钢琴键盘**（C3–B5，点击试听）。

### 4. 系统功能

练习统计与趋势图、错题本（去重计数 + 分类 + 一键重放）、成就徽章、音色选择（纯音 / 钢琴 / 电钢琴 / 管风琴 / 拨弦 / 钟琴 / 合成垫）、音量、A4 基准音高（默认 440Hz，可调）、自动播放、快捷键、彩带动效、深色 / 浅色主题、数据导出（JSON）与导入、一键清空。

**快捷键**：`1`–`9` 选择选项 · `空格` 重播（节奏模仿页为击拍）· `Enter` 下一题 · `Esc` 关闭弹窗。

## 四、技术方案

| 关注点 | 方案 | 理由 |
|---|---|---|
| 音频合成 | 自研 Web Audio 合成引擎（`js/audio.js`） | 无需采样文件，离线可用；纯音最适合音程训练，其余音色用加法合成 + 谐波包络实现 |
| 五线谱渲染 | VexFlow 4（本地 `vendor/vexflow.js`，含全部音乐字体） | 成熟的制谱库；本地固定版本避免联网依赖 |
| 临时记号 | 自研「调号 + 小节内状态机」 | 精确控制还原号与升/降号的出现时机，并支持跨小节复位（已用 A/B 测试验证） |
| 多小节布局 | 每小节独立 `Stave` 横向拼接（`renderSystem`） | 比 `BarNote` 的间距行为更可控，小节线稳定 |
| 音高检测 | 自研归一化互相关（NCC）+ 抛物线插值（`js/pitch.js`） | 零依赖；限制滞后搜索范围保证 30fps 实时性；取首个超阈峰值抑制八度误判 |
| 数据持久化 | `localStorage`（含内存降级） | 数据不出本机；隐私模式下自动降级为内存存储并提示 |
| 架构 | 原生 ES5 风格 + `WB` 命名空间，无构建步骤 | 双击即可运行；避免 npm / 打包链带来的环境依赖 |

## 三·五、QA 回归指南

谱面类缺陷有个共同的坑：**SVG 根元素默认 `overflow: hidden`**，落在 `viewBox` 之外的元素会被**静默裁掉**——
DOM 里查得到、`querySelectorAll('.vf-notehead').length` 也正常，屏幕上却什么都看不见。
所以「元素数量对不对」不等于「画面对不对」，必须做几何校验。

三层验证，各管一段，缺一不可：

| 层 | 命令 | 覆盖范围 | 通过标准 |
|---|---|---|---|
| 逻辑层 | `node tools/test-notation.js` | 拼写 / 调号 / 节奏型数据 | `ALL OK` |
| 结构层 | `node tools/test-e2e.js` | jsdom 加载真实页面的全部视图与交互 | 5518 项全过 |
| 版式层 | `bash tools/browser-measure.sh` | 真实浏览器：裁切检测 / 全组合压力 / 音符数比对 / 小节时值 | 31 项全过，退出码 0 |

版式层三条核心断言（都是本项目真实踩过的缺陷，已固化为回归项）：

1. **所有 SVG 的内容包围盒不得越出 `viewBox`** —— 逐路由扫描整个应用的 `<svg>`。
2. **视唱谱面 648 组参数组合**（调性 × 拍号 × 小节数 × 难度）**音符 100% 落在视口内**。
3. **期望音符数 == 实际渲染音符数**，且**每小节总时值 == 拍号拍数**（非数值时值同样判失败）。

> `node tools/test-e2e.js` 需要 jsdom（`NODE_PATH` 指向安装 jsdom 的 `node_modules`）；
> `browser-measure.sh` 需要 `agent-browser`。二者在缺少依赖时会直接报错而非静默跳过。

## 五、数据与隐私

- 所有练习数据（设置、统计、错题本、成就）**仅保存在本机浏览器 `localStorage`**，不上传任何服务器。
- 麦克风音频**仅在浏览器内存中实时分析**，不做录制、不做上传。
- 设置页可一键导出 JSON 备份，或从备份恢复；也可一键清空全部数据。

## 七、已知限制与后续可扩展

**当前限制**

1. 视唱音准检测与逐音模唱**必须通过 `http://localhost` 访问**（浏览器安全上下文要求）。
2. 节奏部分覆盖 2/4、3/4、4/4 拍，**尚未实现 6/8 拍**（央音考纲含 6/8）。
3. **二声部旋律听写**与**和弦连接（四声部）听写**未实现——这两项属于作曲、指挥方向的进阶笔试内容。
4. 音色为**合成音色**而非采样音色；如需真钢琴采样，可在 `js/audio.js` 的 `VOICES` 中接入采样播放。
5. 单音听辨采用**标准音 a1 参照**的相对音高训练方式，不是绝对音感训练（绝对音感训练需长期专门方法）。
6. **窄屏 + 高密度谱面会整体缩小**：视唱谱面按「每小节音符数」分配宽度，容器装不下时会把 SVG 加宽后
   由 CSS 等比缩放（保证不裁切、不溢出）。390px 宽的手机上，4 小节 × 高级（约 17 个十六分音符）
   会缩到约 0.5 倍，音符头约 6px。桌面端（≥ 1024px）不受影响。
   实测最小音符间距：1280px 下 ≥ 3.8px，390px 下极端情形相邻音符头可能相切（约 −1px）。

**可扩展方向**

- 6/8 拍与更多节奏型；自定义节奏型编辑器
- 二声部 / 四声部听写（多谱表渲染）
- 视唱跟唱评分（按时间轴对齐的旋律级评分）
- 移调练习、四声部和声写作辅助
- 练习计划与间隔重复（SRS）算法驱动的错题复习排程

## 八、常见问题（Troubleshooting）

**Q1：双击 `start.bat` 后出现一堆 `'xx' 不是内部或外部命令`、`'跨敤'`、`'锟斤拷'` 之类的报错。**

这是批处理文件的**编码/换行符**问题，原因有两层，本项目已修复，若你自行改动过该文件请按下面检查：

1. **换行符必须是 CRLF。** 用 LF 的 `.bat` 会让 `cmd.exe` 无法正确解析 `if (...)` 多行块与标签。
   检查：VS Code 右下角应显示 `CRLF`，若是 `LF` 点一下切换后保存。
2. **中文必须按系统代码页存。** 简体中文 Windows 的代码页是 936(GBK)，`.bat` 里写 UTF-8 中文会被解码成乱码。
   检查：用 VS Code「Save with Encoding → GB2312/GBK」另存；或干脆保持纯英文。

命令行自查（在项目目录执行）：
```bat
powershell -NoProfile -Command "$b=[IO.File]::ReadAllBytes('start.bat'); \
  '非ASCII字节数: ' + ($b | Where-Object {$_ -gt 127}).Count; \
  'CRLF数: ' + ([regex]::Matches([Text.Encoding]::Latin1.GetString($b), \"`r`n\")).Count"
```
正常应输出 `非ASCII字节数: 0`。

**Q2：页面能打开，但「开始模唱」「开始监听」点了没反应 / 提示不支持麦克风。**

必须以 `http://localhost` 打开（用 `start.bat` 或 `start.sh` 启动），不能是 `file://` 双击打开——浏览器只在安全上下文里允许麦克风。

**Q3：端口 8765 被占用。**

换端口启动：`start.bat 9000`，或 `python -m http.server 9000`。

**Q4：终端里中文显示成乱码。**

`cmd.exe` 默认代码页 936，Node 输出的 UTF-8 中文会乱码。本项目 `tools/serve.js` 与 `start.bat` 已刻意只用 ASCII 输出；若你在自己的脚本里输出中文，先执行 `chcp 65001` 切到 UTF-8 代码页。

**Q5：五线谱一片空白。**

确认 `vendor/vexflow.js` 存在（约 992KB）。加载失败时页面会弹出提示。
